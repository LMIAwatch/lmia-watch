# Brand files

The site mark is a two-column register with one entry cell filled, drawn on a
16 px grid so it stays sharp at any whole-number scale. Navy is `#1c3d6a`.

| File | Use |
|---|---|
| `mark.svg` | The mark alone, navy on transparent. Change the fill to `#ffffff` for use on navy. |
| `lockup.svg` | Mark plus the wordmark "LMIA Watch" as live SVG text. |
| `x-profile-400.png` | Profile photo for X: white mark on navy, 400 by 400. X crops it to a circle; the mark sits inside the circle. |
| `x-profile-1024.png` | The same at 1024 by 1024 for services that want a larger upload. |
| `x-profile-light-400.png` | Navy mark on white, if a light avatar is wanted. |
| `x-header-1500x500.png` | Header image for X at its native 1500 by 500. The lockup sits in the centre, clear of the avatar overlap at the bottom left. |

The PNGs are generated, not drawn: `python brand/make_brand.py` rewrites them.
The wordmark uses Public Sans Bold (`fonts/`, SIL Open Font License), the same
typeface as the site. The Regular and SemiBold files beside it are read by the
pipeline when it draws the daily X card (`pipeline/lmia_pipeline/social_card.py`).

The site's own icon files live in `site/public/` (`favicon.svg`, `favicon.ico`,
`apple-touch-icon.png`) and are generated by `site/scripts/make-icons.py`.
